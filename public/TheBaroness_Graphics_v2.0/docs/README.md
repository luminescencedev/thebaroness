# THE BARONESS — GRAPHIC SYSTEM V2.0

Une direction graphique pour le tracker Deadlock The Baroness **telle qu'elle existe actuellement**.

## Pourquoi la direction change

L'ancien kit, or et ivoire Art Deco tres orne, n'etait pas coherent avec `src/styles/tokens.css` (fond #060709, violet #5B4BF0, texte #F4F5F7), Geist, les cartes translucides et la navbar pilule du frontend reel.

Le kit V2 prefere : minimalisme noir froid / violet, monogramme B / arche d'hotel et petit motif keyhole. Le lore reste une allusion, jamais une surcharge de decorations.

## Contenu

- `logos/svg` : marque, mot-symbole, logos complets, versions couleur/mono/inverse.
- `logos/png` : exports haute resolution transparents.
- `favicons` : SVG, PNG 16/32/48/64/180/192/512, favicon.ico, webmanifest.
- `graphics/svg` : elements decoratifs et etats vides vectoriels.
- `backgrounds` : quatre fonds atmospheriques WebP plus une version recommandee adoucie.
- `social` : quatre OpenGraph JPEG 1200 x 630 et un carre social 1080 x 1080.
- `react` : composant Wordmark compatible React Router et pictogramme generique.
- `styles` : CSS optionnel, et palette de reference.
- `docs` : guide d'integration et inventaire.
- `preview/brand-board.html` : apercu local interactif de la direction graphique (ouvrir dans un navigateur).

## Usage ideal

Remplacer d'abord le favicon et le wordmark, puis eventuellement les metadonnees sociales. Garder les ambiances pour les grandes surfaces uniquement. Le logo compact doit rester lisible dans la navbar flottante.
